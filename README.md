# Gencouv Copy Trading Website

Clean Next.js frontend focused on broker-connected copy trading, with Expert Advisors, indicators and trading utilities as secondary services.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

Import `limitlessnx/Gencouv`, keep the root directory at the repository root, select Next.js and deploy the `main` branch.

All visible account values are illustrative interface examples. Replace them with verified production information before launch.
